# Extension Activity

Extend the `Door` class you created in the tutorial by giving the door additional properties and behaviours.

## Requirements

* Add a `color` property that stores the colour of the door and is given a starting value when the `Door` object is created.
* Add a `times_opened` property that starts at `0` and increases by **1** every time the door is successfully opened. Print how many times the door has been opened when it is opened.
* Add a `paint(color)` method that changes the door's `color` property to the provided colour.
* Add a `knock()` method that prints `"Knock knock!"` when called, but only if the door is closed.
* Update the program that uses the `Door` object to include 2 separate instances of the door object.
* Update the program that uses your `Door` object so you can demonstrate that each new property and method works correctly on each door.
